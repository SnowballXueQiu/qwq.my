打开 qwq.my，你先看到的是一张米白色的工程图纸，上面用线稿画着一个 QwQ。往下滚，线稿长出厚度，图纸从脸开始裂开，碎片飞向镜头，镜头穿过纸洞进入一个暗场的 3D 世界。之后每个板块都是这部「MV」里的一幕，最后碎片飞回来，重新拼成一张纸。

这篇把它从头到尾拆开讲一遍。

## 技术栈

| 部分 | 用的是什么 |
| --- | --- |
| 框架 | Next.js 16（App Router）、React 19 |
| 3D | three.js r187、React Three Fiber 9、drei |
| 着色器 | 全部手写 GLSL（WebGL2） |
| 动画与滚动 | GSAP、Lenis，以及自己写的逐拍滚动 |
| 视频 | Remotion（页面里直接嵌 Player） |
| 文章 | MDX（next-mdx-remote-client）、remark-gfm、rehype-pretty-code + Shiki |
| 其他 | d3-delaunay（撕纸）、zustand（状态） |
| 部署 | Docker + Cloudflare Tunnel |

整个项目大约一万一千多行 TypeScript 和 GLSL。配色只有三种：纸 `#F1EDE4`、墨 `#141414`、朱红 `#E8402A`。暗场就是纸和墨对调。

## 骨架：一块画布，七张图纸，一个场景时间

页面底层是一块铺满屏幕的 `<Canvas>`，所有 3D 都画在这里；文字、面板、HUD 是普通 DOM，叠在上面。

首页由七张「图纸」组成：你好、关于我、技能、项目、经历、文章、联系。每张图纸是一个很高的 `<section>`，里面的内容 `position: sticky` 钉在屏幕上，图纸有多高，这一幕就演多久。

3D 那边不直接看滚动条，而是看一个叫**场景时间**的数：

```ts
// 整数部分是第几张图纸，小数部分是这张图纸滚过了多少
// 0 = 首页顶端，1 = 「关于我」开始，2.5 = 技能滚到一半
export function getSceneTime(): number
```

镜头、每个场景的出场退场、明暗切换，全部只读这一个数。这样 DOM 和 3D 永远对得上，改一张图纸的长度，3D 那边什么都不用动。

## 渲染：一种材质，一张 G-buffer，一个把它「画」出来的 pass

这个网站里几乎所有 3D 物体都用同一种材质。它不输出颜色，而是往两张渲染目标里写数据（WebGL2 的 MRT）：

```glsl
layout(location = 0) out vec4 gColor;   // 明暗、是否强调色、填充方式
layout(location = 1) out vec4 gNormal;  // 视空间法线 + 物体 id

gColor  = vec4(tone, accent, uFill, 1.0);
gNormal = vec4(n * 0.5 + 0.5, uObjectId);
```

明暗用的是半兰伯特，光从左上方来，就像画画时约定俗成的光源。每个材质创建时分到一个物体 id。

然后一个全屏的合成 pass 把 G-buffer「画」成一张图：

- **墨线**：对深度、法线和物体 id 分别做 Sobel 边缘检测。深度断开的地方是轮廓，法线突变的地方是折痕，id 不同的地方是两个物体的交界。三者取最大值就是墨线，再加一点缓慢的抖动，像手画的线。
- **网点和排线**：明暗决定网点有多大、排线叠几层，都在屏幕空间里算，所以无论物体多大，网点密度都一致。
- **纸纹**：纸面的纹理是固定的，不会每帧重新生成。
- **纸和墨对调**：一个 `uInvert` 在 0 和 1 之间插值，亮场和暗场是同一个 shader。有一种填充方式叫 `sheet`，表示「真正的纸」，它不跟着反色，所以撕碎的纸片在暗场里依然是纸。

合成之后还有一层镜头效果：色差、CRT 桶形畸变和扫描线、高速滚动时从消失点放射出的速度线、点击空白处的墨水冲击波、暗角。

有一条硬规矩：**不闪屏**。光敏性癫痫的人看到整屏闪白会很难受，所以切镜只用轻微的推镜和一小段故障条纹，没有任何全屏闪烁；系统开了「减少动态效果」时，这些效果全部关掉。

### 清晰度

手机屏幕是 3 倍像素密度，画布如果只按 1 倍渲染，3D 文字会糊成一片。现在画布按像素预算决定倍率：大约 320 万像素封顶，所以手机能用 2 倍，大显示器少一些。如果设备跑不动（drei 的 `PerformanceMonitor` 报告掉帧），只降一次，降四分之一，避免滚动中途反复重新分配画布。

经历里的路牌是贴在 3D 场景里的 DOM（CSS 3D 变换）。WebKit 按布局尺寸栅格化这类图层，字排得小、再被变换放大就会发虚。所以这些元素先按 2 倍尺寸排版，再让变换缩小一半显示。

## 开场：170 块碎片，一次绘制调用

开场的那张图纸，其实是 170 块碎片严丝合缝拼起来的。碎片用 d3-delaunay 生成 Voronoi 图：45% 的种子点聚在 QwQ 的脸周围，所以裂口从脸开始，越往外碎片越大。

所有碎片合并成一个 `BufferGeometry`，只用一次绘制调用。每个顶点除了位置和法线，还带三样东西：

- `aCenter`：所在碎片的中心；
- `aRand`：一组随机数，决定旋转轴和飞多远；
- `aDelay`：离裂口有多远（0 到 1）。

顶点着色器拿全局的 `uBreak` 减去自己的延迟，就知道这块碎片进行到哪一步了：

```glsl
float local = uBreak - aDelay * 0.6;
// 还没轮到的碎片保持原样：任何浮点运算都会在接缝处漏出针孔
if (local > 0.0) {
  float lift = smoothstep(0.0, 0.12, local);
  float t = clamp((local - 0.06) / 0.5, 0.0, 1.0);
  float e = t * t;
  vec3 axis = normalize(aRand - 0.5 + vec3(0.0, 0.0, 0.001));
  mat3 R = rotateAxis(axis, e * (2.5 + aRand.x * 5.0));
  pos = aCenter + R * (pos - aCenter);   // 绕自己的中心翻转
  nrm = R * nrm;
  vec3 away = normalize(vec3(aCenter.xy * 0.25, 1.0));
  pos += away * e * (16.0 + aRand.y * 18.0);  // 朝镜头飞出去
}
```

那个 `if` 很重要：还没碎的部分一个字节都不能动，否则相邻碎片之间会因为浮点误差漏出一条条细缝。

碎片飞走后，六个桌面小玩具会从洞里蹦出来：鸭子、键帽、马克杯、纸飞机、软盘、方块。都可以戳，也可以按住拖着转。在键帽上依次按 Q、W、Q 会触发派对模式。

## QwQ：一个颜文字做的吉祥物

QwQ 的五官都是程序生成的几何体：笔画是 `TubeGeometry` 加两头的球形端帽，看起来像一笔画出来的线。眼睛是一个圆环加一条尾巴（所以是 Q），里面有会跟着鼠标看的瞳孔。

表情是颜文字，每个部件都可以单独弹出、收起，带一点回弹：

| 表情 | 什么时候出现 |
| --- | --- |
| `QwQ` | 平时 |
| `OwO` | 鼠标停在脸上 |
| `>w<` | 被戳了一下 |
| `QAQ` | 3 秒内被戳 5 次，或者鼠标离开了窗口 |
| `@w@` | 把鼠标甩得太快，眼睛变成转圈的螺旋 |
| `-w-` | 8 秒没动，开始冒 z |
| `^w^` | 到了联系页，还会挥手 |

`QAQ` 是撇着嘴、皱着八字眉，抬头看你，眼泪从眼眶下面一颗一颗冒出来，滑一小段就淡掉。手机上有个坑：手指离开屏幕时，浏览器会报告「指针离开了页面」，QwQ 一度以为你走了，每摸一下屏幕就哭一次。现在只有鼠标真的离开才算。

## 镜头：关键帧和不会冲过头的样条

镜头是一串关键帧：在某个场景时间，镜头在哪、看哪、歪多少度。关键帧之间用**单调三次样条**（Fritsch–Carlson 方法）连接：

```ts
// 相邻两个关键帧的值相同（一个停靠点），切线就是 0：镜头真的停住
if (d[i] === 0) {
  m[i] = 0;
  m[i + 1] = 0;
  continue;
}
```

普通的 Catmull-Rom 样条在两个相同的关键帧之间会稍微冲过头再回来，镜头就会在本该停住的地方晃一下。单调样条不会超调，速度在每个关键帧处也是连续的。

在关键帧之上，导演还加了几层手持感：鼠标位置会轻轻带动镜头，滚得越快视角越广，切镜时有一个缓慢的推镜。手机竖屏用另一套关键帧，比如项目屏幕在手机上会几乎正对镜头，并后退到能装下整块屏幕的距离。

点右上角的「全景」，镜头会拉到高空，整条飞行路线和每一幕的布景变成一张 3D 地图，点任何一幕就飞过去。

## 滚动：前半段一拍一拍，后半段一路到底

这是改动最多的部分。最初是普通的平滑滚动，问题是滚轮一转好几圈、手机猛地一甩，技能和项目就一闪而过。现在滚动分两段。

**前半段逐拍吸附。** 首页、撕纸后的玩具、关于我、地图、每一张技能卡、每一块项目屏幕，各是一「拍」。Lenis 有一个 `virtualScroll` 钩子，可以在它处理滚轮和触摸之前截下来，我在这里接管：

- 滚动先把画面朝下一拍「拉」过去一点，带阻尼；累计滚够大约四分之一屏（普通鼠标滚轮约三格）才真正滑过去，滑行时长固定、缓入缓出；没滚够就弹回来。
- 一次手势最多走一拍。滚轮连转好几圈、触控板甩出去的惯性尾巴都会被吞掉；但如果在惯性快结束时又猛推一下（滚动量先衰减、再突然变大），会被识别成一次新的手势。
- 滑行途中再来一次手势，会等这一拍落稳再走下一拍。
- 手机上直接拦截 `touchmove`，自己判断拖动的距离和速度。
- 键盘方向键、空格、PageUp/PageDown 也是一次一拍。

**后半段连续滚动。** 从经历的第一个节点开始，一直到页尾都是平滑的连续滚动，镜头沿着公路一路往前骑，不再在每个节点停一下。只有一个例外：猛甩会在文章那一拍被接住，不会一下冲到页尾。

还有个和 sticky 有关的坑。面板里的文字是逐行「打」出来的，最初用 GSAP ScrollTrigger 按预先量好的位置触发，但内容是钉在屏幕上的，预先量的位置和屏幕上实际看到的对不上，来回滚几次，关于我的卡片就空了。现在每次滚动都直接看面板此刻在屏幕上的位置：露出超过 15% 就打字，整个掉到屏幕下方才收起。

## 各幕的细节

**关于我。** 一段写成 TypeScript 的自我介绍，`init(me);` 这几个字是从平面上跳出来的 3D 挤出字。3D 字的字体是 Archivo Condensed 和 JetBrains Mono，转成了 typeface JSON；中文只走 DOM，用系统字体，因为中文网络字体动辄几 MB，Google Fonts 在国内也打不开。

**足迹地图。** 镜头转过去俯看一张中国地图。数据来自阿里云 DataV GeoAtlas，用 Douglas–Peucker 算法把边界简化到大约 0.04 度（岛屿和九段线保留得更细），最后只有 108KB。每个省级行政区单独挤出成一块，去过的升高、染成朱红，每个去过的地方插一根针。手机屏幕小，只插针不挂地名，地方越来越多也不会挤成一团。

**技能。** 每组技能是路边的一个站台，挤出字一个个飞进来锁住；左边的物料清单（BOM）同步高亮当前这一组。

**项目。** 镜头在一排巨大的屏幕之间穿行。屏幕的脸是一个着色器：扫描线、慢慢滚过的亮条，鼠标悬停时噪点带变多。

**经历。** 一条蜿蜒的公路，每个节点是一块路牌。一只骑自行车的鹈鹕在镜头前面 13 个单位处骑行，车轮按镜头走过的距离转，往回滚它就掉头。公路尽头是一座 GitHub 城市：近一年每天的贡献数变成一栋楼，镜头先在楼群脚下仰视，再升到高空，整年读起来就是熟悉的贡献格子。数据不用 token，直接解析 GitHub 公开主页上的贡献日历，8 秒拿不到就用仓库里的快照。

**年度回顾。** 经历里有一个「播放年度回顾」的按钮，弹出的是用 Remotion 写的一段视频：七个场景，30 帧每秒，共 1070 帧，大约 36 秒，直接用 `@remotion/player` 在浏览器里实时渲染，没有预渲染的视频文件。

**文章和联系。** 文章是一排悬浮的纸页；到了联系，碎片飞回来拼成纸，世界回到亮场，QwQ 变成 `^w^` 挥手。

## 交互和彩蛋

- **终端**：按 `` ` `` 或 `⌘K` 打开，支持 Tab 补全和上下键翻历史。命令有 `help`、`ls`、`cd`、`cat`、`now`、`contact`、`projects`、`open`、`blog`、`read`、`lab`、`whoami`、`neofetch`、`date`、`echo`、`history`、`lang`、`qwq`、`debug`、`clear`、`exit`。`sudo rm -rf /` 会让整个网站「崩溃」，然后重新开机。
- **Debug 打虫**：低多边形的 bug 从纵深飞向镜头，点它就碎。60 秒、3 条命，连击加分，最高分存在 `localStorage`，QwQ 在角落给你加油或者哭。
- **Konami 秘籍**：↑↑↓↓←→←→BA，全场派对。
- **实验室**：两个可以玩的 GPU 小实验。一个是墨水流体：标准的稳定流体解法，每帧 20 次 Jacobi 迭代解压力；另一个是 Gray–Scott 反应扩散，长出珊瑚和斑点一样的花纹。
- **声音**：全部用 WebAudio 现场合成，没有一个音频文件：撕纸声、切镜的呼啸、键帽的咔嗒、冲击波的闷响、打虫的音效，还有一个随滚动速度开合滤波器的环境音。默认静音，选择会被记住。

## Next.js 16 那一侧

- **路由和双语**：每个页面都在 `/[locale]` 下。Next 16 把 middleware 改名叫 `proxy.ts`，我在里面做两件事：按 `Accept-Language` 把访客送到 `/zh` 或 `/en`，以及把 `www.qwq.my` 301 到主域名。
- **缓存**：开了 `cacheComponents`，读文章、读 GitHub 数据的函数标了 `"use cache"`；首页大部分是静态的，少量动态内容流式补上（Partial Prerendering）。
- **文章**：每篇文章一个文件夹，`zh.mdx` 和 `en.mdx` 至少写一个，缺的语言自动回退到另一种。代码高亮在服务端用 Shiki 做好，表格走 GFM。还有 RSS（`/zh/feed.xml`）和自动生成的分享图。
- **读文章的时候**，3D 世界不会消失：纸面铺满，QwQ 缩到角落陪你读。

## 部署

网站跑在一台自己的服务器上，用 Docker：

- 三阶段构建（依赖、构建、运行），基础镜像 `node:22-alpine`，Next 输出 `standalone`，最终镜像约 230MB；
- `docker compose` 里两个服务：`web` 是网站本身，**不向宿主机暴露任何端口**；`tunnel` 是 cloudflared，在 Docker 内网里直接连 `web:3000`。

```yaml
services:
  web:
    build: .
    restart: unless-stopped
  tunnel:
    image: cloudflare/cloudflared:latest
    depends_on: { web: { condition: service_healthy } }
    command: ["tunnel", "run", "${TUNNEL_ID}"]
    environment:
      TUNNEL_URL: http://web:3000
```

访问只能走 Cloudflare Tunnel：服务器主动连出去，不需要开任何入站端口，DNS 里也只有 Cloudflare 的 IP，所以源站 IP 不会暴露。服务器连不上 GitHub，部署方式就是把代码同步过去，`docker compose up -d --build`。
