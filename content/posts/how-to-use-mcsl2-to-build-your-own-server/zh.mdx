## 一、下载

访问 [点击跳转](https://drive.zyghit.cn/s/y1Fk?path=%2F)，根据你的系统选择合适的版本进行下载，这里以 Windows 平台为例进行演示：  

![下载页：选 Windows 版的压缩包](/blog/how-to-use-mcsl2-to-build-your-own-server/01.webp)

下载过程中，若浏览器阻止下载，请选择“保留”或“允许”继续下载。如果网络较慢，建议使用下载工具加速。

---

## 二、打开

解压下载好的压缩包并将其移动到合适的位置，找到文件夹中的 `MCSL2.exe`，双击打开：  

![解压后的文件夹里找到 MCSL2.exe](/blog/how-to-use-mcsl2-to-build-your-own-server/02.webp)

若遇到防火墙弹窗，请选择“允许访问”。如果提示需要管理员权限，请右键选择“以管理员身份运行”。

---

## 三、配置一个新的服务器

点击界面中的 **新建** 图标，建议选择 **简易模式**，并根据自己的需求进行配置。以 Purpur-1.21.1 版本服务端为例，内存设定为 1024M-4096M（1G = 1024M），选择 Java 版本为 21.0.2。  

如果未安装 Java 或服务端文件，可点击界面中的 **下载 Java** 和 **下载核心** 按钮进行下载（基岩版也支持，详见软件内部）。  

![主页左侧的「新建」](/blog/how-to-use-mcsl2-to-build-your-own-server/03.webp)

![简易模式：选好 Java、填好内存、下载核心，最后保存](/blog/how-to-use-mcsl2-to-build-your-own-server/04.webp)

### 核心版本与 Java 版本对照表  

| 核心版本                      | Java 版本                 |  
|-------------------------------|---------------------------|  
| 1.0 - 1.11.x                 | Java 6 / Java 7 / Java 8  |  
| 1.12(17w13a) - 1.16.5        | Java 8                    |  
| 1.17(21w19a) - 1.17.1        | Java 16 / Java 17         |  
| 1.18(1.18-pre2) - 1.20.4     | Java 17                   |  
| 1.20.5(24w14a)               | Java 21                   |  

在配置过程中，如果不确定某些选项的意义，可以点击界面上的提示信息或参考相关文档。

---

## 四、启动服务端

点击 **管理**，找到刚刚配置好的服务器，点击 **启动** 按钮，并 **同意 EULA 协议**。稍等片刻，当提示“服务器启动完毕，详情请到快捷终端查看。”时，你就可以进入服务器了。  

在 Minecraft 客户端添加一个服务器，IP 填写为 `127.0.0.1:25565` 即可进入。同时，你可以在 `server.properties` 文件中编辑端口等其他配置，详情可参考 [Minecraft Wiki](https://zh.minecraft.wiki/w/Server.properties)。  

![主页右下角的「选择服务器」](/blog/how-to-use-mcsl2-to-build-your-own-server/05.webp)

![管理页：找到刚配好的服务器，点「启动」](/blog/how-to-use-mcsl2-to-build-your-own-server/06.webp)

![启动完毕，右下角弹出提示](/blog/how-to-use-mcsl2-to-build-your-own-server/07.webp)

如果服务器启动失败，建议检查日志文件或尝试更改 Java 版本。

---

## 五、配置端口转发

如果想让其他小伙伴进入你的服务器，需要配置端口转发（内网穿透）。目前有多个平台可供选择，例如 Sakura Frp，其官网有较为详细的教程。  

配置端口转发后，可以通过外网 IP 地址让朋友们连接到你的服务器。请确保选择合适的端口并在路由器中完成正确配置。  

至此，大功告成，你已成功运行了一台属于自己的 Minecraft 服务器！
