整个网站只有一种材质。它不输出颜色，而是往两张渲染目标里写数据：

| 通道 | 内容 |
| --- | --- |
| `gColor.r` | 明暗（半兰伯特） |
| `gColor.g` | 是否用强调色 |
| `gColor.b` | 填充方式：排线、纸、墨 |
| `gNormal.xyz` | 视空间法线 |
| `gNormal.a` | 物体 id |

然后一个全屏 pass 把它们「画」出来：深度和法线的 Sobel 边缘是墨线，明暗决定网点有多大、排线有几层，物体 id 不同的地方也补一条线。

亮场和暗场只是同一个 shader 里纸和墨对调，`uInvert` 从 0 到 1。
